Set up in about three minutes

The translator now runs on ChatGPT — the account you already have. No new account, no waiting on verification emails. You sign in with your normal ChatGPT login, make a key, and paste it here. Once, and never again.

Step 1 of 4: Sign in

Tap the button below to open OpenAI's key page. Sign in with the same login you use for ChatGPT. If it offers "start building" questions, tap through with the suggested answers. Then come back here.

Open platform.openai.com

This browser would not open the site in a new tab. Open this address in any other browser window, then come back here:

platform.openai.com/api-keys

It opens in a new tab; this guide stays right here, waiting for you.

Step 2 of 4: Add credits

Look at the bottom-left corner of OpenAI's page. If you see Go to billing just above the profile icon, tap it. If you don't, tap the profile icon in the bottom left, then Organization settings (on some accounts it says Personal — either one is fine), then Billing in the left pane.

Tap Buy credits and add $50 to $100 — whatever you're comfortable with. This one balance covers both of the keys you'll make in the next steps. Then turn on auto reload, so it tops itself up and the translator never stops working on you. A translation costs a fraction of a cent, and the app shows you the running total right on its main screen.

Step 3 of 4: Create your key

Tap API keys in the left pane, then the Create new secret key button.

A box opens asking who owns it. Leave You selected — the first choice, already picked — and ignore "Service account". Name it Hebrew Translator, leave Project and Permissions exactly as they are, and tap Create secret key. Then tap Copy — your key is ready to paste.

Step 4 of 4: Paste it here

Paste the key you just copied. It stays on this phone and is sent only to OpenAI.

✅ Great — the translator app now has AI features!

One last thing: make a second key the same way — API keys → Create new secret key, keep You selected, name it Aetna Hub — copy it and paste it below. The page sends it straight to the company Hub for Caleb — nothing to text or email, and it never stays on this phone.

You're all set

Your key works and is saved on this phone. Type English and you get natural Israeli Hebrew with the vowel marks double-checked by a specialist. Tap the Share button in Safari and choose Add to Home Screen to keep it like a real app.
