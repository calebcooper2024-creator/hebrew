Settings

The app talks directly to Claude, Anthropic's AI, for translation. It needs an API key once. The key is stored only on this device, never sent anywhere except to Anthropic.

The double-check sends just the Hebrew sentence to Nakdan, a free tool from Dicta, an Israeli research nonprofit whose vowel-pointing is the best there is. If it spots a wrong mark, the app corrects itself.
